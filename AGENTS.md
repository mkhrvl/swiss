# Repository guidance

Before changing code, tests, or build configuration, read [the web conventions](docs/web.md). Use [the development guide](docs/development.md) for run, verification, and distribution commands.

A change is done when `pnpm verify` passes along with the browser checks from the web conventions that cover it. When a tool's behavior, limits, or the tool list changes, update [the tool guide](docs/tools.md) and the README tool table.
